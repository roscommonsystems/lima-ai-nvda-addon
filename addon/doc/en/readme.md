# LIMA NVDA Add-on

LIMA (Low-Vision Intelligent Machine Assistant) integration for NVDA. A light, free companion to the LIMA desktop app.

## Commands

- **NVDA+Shift+D**: Describe what is currently on the screen. NVDA speaks an AI description of the active screen.
- **NVDA+Shift+L**: Announce that the LIMA add-on is running (health check).

## Setup

Open NVDA menu → Preferences → Settings → **LIMA**, and paste your **OpenRouter API key**. You can also change the **model** (default `openai/gpt-4o-mini`).

This add-on only describes the screen on demand. For the full hands-free experience, including continuous narration and voice-driven computer control, use the **LIMA desktop app**.
